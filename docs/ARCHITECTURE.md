# Architecture Overview

این پروژه بر اساس **Clean Architecture** طراحی می‌شود تا توسعه ماژولار و تست‌پذیری بالا حفظ شود.

## لایه‌ها
- **Domain**: موجودیت‌ها، قوانین پایه، Value Objectها، Enums
- **Application**: Use caseها، سرویس‌ها، DTOها، اعتبارسنجی
- **Infrastructure**: دیتابیس، پرداخت‌ها، پیام‌رسانی
- **WebUI (Blazor Server)**: رابط کاربری و صفحات ادمین/راننده/مشتری

## ویژگی‌های کلیدی
- **چندزبانه**: Resource-based + مدیریت ترجمه توسط ادمین
- **تم‌بندی**: Light/Dark/Auto
- **ماژول پرداخت**: Strategy Pattern برای افزودن درگاه‌های جدید

## اصول
- وابستگی‌ها به سمت داخل (Domain مستقل)
- جداسازی منطق کسب‌وکار از UI
- مستندسازی تغییرات و تصمیمات کلیدی
