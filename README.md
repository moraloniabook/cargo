# Cargo Transport Platform (Blazor)

این مخزن نقطه‌ی شروع پروژه‌ی شرکت حمل‌ونقلی شما است. هدف ما ساخت یک سامانه ماژولار، چندزبانه و قابل توسعه با **Blazor Server** و معماری Clean Architecture است.

## چشم‌انداز فازبندی (Step-by-step)
ما به‌صورت مرحله‌ای پیش می‌رویم و تا اتمام همه موارد، در هر مرحله وضعیت را یادآوری می‌کنم.

1. **فاز 0: برنامه‌ریزی و اسکلت پروژه** ✅ (این مرحله)
2. **فاز 1: هسته دامنه (Domain) + مدل‌های پایه**
3. **فاز 2: Application Layer + سرویس‌ها و DTOها**
4. **فاز 3: Infrastructure Layer (EF Core + SQL Server + پرداخت‌ها)**
5. **فاز 4: WebUI (Blazor Server + MudBlazor + تم و i18n)**
6. **فاز 5: مستندات نهایی + راهنمای استقرار**

## الزامات کلیدی
- **چندزبانه** با قابلیت افزودن زبان جدید توسط مدیر ارشد.
- **معماری ماژولار** برای افزودن درگاه‌های پرداخت بدون تغییر ساختار اصلی.
- **تم روشن/تیره/خودکار**.
- **کدنویسی خوانا و قابل توسعه**.
- **مستندات کامل**.

## شروع کار
در قدم بعدی، فاز 1 را شروع می‌کنیم و **مدل‌های دامنه** و قراردادهای اصلی را می‌سازیم.

> یادآوری: طبق درخواست شما، تا تکمیل تمام مراحل، وضعیت پیشرفت را در هر مرحله اعلام می‌کنم.
