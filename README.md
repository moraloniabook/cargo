# سامانه حمل‌ونقل - نقشه راه پیاده‌سازی (شروع مرحله‌ای)

این مخزن برای پیاده‌سازی تدریجی سامانه حمل‌ونقل شما با **Blazor Server + .NET 8** آماده شده است. هدف این است که **مرحله‌به‌مرحله** جلو برویم و تا پایان همه موارد، شما را برای ادامه یادآوری کنم.

## اصول کلیدی پروژه
- **معماری ماژولار** و قابل توسعه (Clean Architecture).
- **چندزبانه** با قابلیت افزودن زبان جدید توسط مدیر ارشد.
- **تم روشن/تیره/خودکار**.
- **درگاه‌های پرداخت قابل افزودن** بدون تغییرات گسترده در هسته.
- **مستندسازی در هر مرحله**.

## فازبندی اجرا (گام به گام)

### فاز 1 — اسکلت پروژه و زیرساخت
1. ایجاد Solution با ساختار Clean Architecture (Domain/Application/Infrastructure/Web).
2. راه‌اندازی Blazor Server و MudBlazor.
3. افزودن سیستم چندزبانه (Resource files + مدیریت زبان‌ها).
4. افزودن سیستم Theme (Light/Dark/Auto).

### فاز 2 — هویت و دسترسی
1. پیاده‌سازی احراز هویت و نقش‌ها (Admin, Operator, Driver, Customer).
2. مدیریت کاربران (ثبت/ویرایش/حذف).

### فاز 3 — ماژول سفارشات
1. ثبت سفارش (وب/تلفن توسط اپراتور).
2. تخصیص راننده و وضعیت‌های سفارش.
3. پیگیری سفارش و تاریخچه.

### فاز 4 — ماژول مالی و کمیسیون
1. مدل بدهکاری/بستانکاری راننده و مشتری.
2. تسویه‌حساب رانندگان.
3. گزارشات مالی.

### فاز 5 — درگاه‌های پرداخت
1. طراحی الگوی Strategy برای درگاه‌ها.
2. پیاده‌سازی درگاه نمونه.
3. امکان افزودن درگاه‌های جدید بدون تغییر در هسته.

### فاز 6 — داشبورد مدیریتی
1. داشبورد آمار و نمودارها.
2. مدیریت مشتریان و رانندگان.
3. مدیریت درخواست‌ها و وضعیت‌ها.

## روش تحویل مرحله‌ای
در هر گام:
- کد مربوطه اضافه می‌شود.
- مستندات همان مرحله درج می‌گردد.
- سپس به مرحله بعدی می‌رویم.

---
اگر آماده باشید، **فاز 1** را آغاز می‌کنم و در هر مرحله به شما یادآوری می‌کنم تا پایان پروژه کامل شود.
